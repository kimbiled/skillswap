# SkillSwap KZ

Доска обмена навыками для студентов Астаны: регистрация, объявления, обмены с подтверждением, отзывы и Skill Coins.

Стек: React 19, TypeScript, Vite, Tailwind CSS 4, Ant Design 6. Сервер — функции Vercel в `api/`, база — Postgres (Neon).

## Деплой на Vercel

1. На [vercel.com](https://vercel.com) → **Add New → Project** → импортируйте репозиторий `kimbiled/skillswap`. Настройки сборки Vercel определит сам (Vite), нажмите **Deploy**.
2. В проекте откройте **Storage → Create Database → Neon (Serverless Postgres)** и подключите базу к проекту для всех окружений. Vercel сам добавит переменную `DATABASE_URL`.
3. **Deployments → последний деплой → ⋯ → Redeploy**, чтобы функции увидели базу.

Таблицы создаются автоматически при первом запросе. Дальше каждый пуш в `main` выкатывается сам.

## Локальный запуск

```bash
npm install
npm run dev       # http://localhost:5173 — сайт и API вместе
npm run build     # проверка типов и сборка в dist/
```

Без `DATABASE_URL` локальный сервер использует встроенную базу PGlite в папке `.data/` (в git не попадает). Чтобы работать с настоящей базой, запустите `DATABASE_URL=… npm run dev`.

## Как работает обмен

1. **Регистрация** (`/register`): логин и пароль, фамилия, имя, возраст, вуз, Telegram и WhatsApp, навыки «научу» и «хочу научиться». До 18 лет — с согласием родителей. **Вход** — `/login`.
2. **Доска** (`/board`): блок «Подходят вам» — сначала взаимные совпадения, потом по рейтингу. Поиск, фильтр «Учат тому, что я хочу», сортировка по новизне или рейтингу.
3. **Контакты** автора сервер отдаёт только после входа и клика «Показать контакты». Дальше: «Связались, договорились» или «Ничего не вышло» — после выбора объявление уходит с доски.
4. **«Мои обмены»** (`/me`): «Связались → Назначили дату → Встретились → Урок прошёл → Автор подтвердил».
5. На шаге «Урок прошёл» — оценка, отзыв и по желанию фото с урока или скриншот переписки. **Автор подтверждает урок** (или «Урока не было» — обмен уходит на проверку). Отзыв публикуется только после подтверждения.
6. **Skill Coins**: урок стоит 10 SC, проведённый урок приносит 10 SC, при регистрации — 10 SC бонуса. Баллы резервируются при «Связались» и переходят к автору после подтверждения. Константы — в `shared/rules.ts`.
7. **Прогресс**: сколько уроков пройдено и проведено, уроки по каждому навыку, рейтинг как учителя, лента уроков.
8. **Premium** оплачивается через WhatsApp (+7 701 012 08 06): кнопка открывает чат с готовым сообщением, счёт отправляется вручную.

## Безопасность

- Пароли хранятся только в виде хеша scrypt с солью. Сессия — случайный токен в HttpOnly-cookie, в базе лежит только его SHA-256.
- После 10 неверных паролей подряд вход блокируется на 15 минут.
- Все правила (статусы, монеты, кто что может подтвердить) проверяются на сервере, интерфейс их только отображает.
- Запросы на запись с чужих сайтов отклоняются (проверка `Origin`, cookie `SameSite=Lax`).
- Чужим пользователям отдаётся только инициал фамилии; контакты — только участникам общего обмена.

## Структура

- `api/` — функции Vercel: `register`, `session` (вход/выход), `state` (данные для страницы), `exchange` (шаги обмена), `photo`
- `api/_lib/` — подключение к базе и схема (`db.ts`), сессии, пароли, ответы (`http.ts`)
- `shared/rules.ts` — правила, общие для сайта и сервера
- `src/lib/store.ts` — состояние на клиенте, вызовы API, рекомендации и прогресс
- `src/pages/` — доска, «Мои обмены», вход
- `src/sections/` — секции лендинга и форма регистрации (`Join.tsx`)
- `src/components/` — навигация, карточка объявления, «бумажные» элементы
- `src/data.ts` — тексты лендинга, список навыков, номер WhatsApp
- `src/index.css`, `src/theme.ts` — токены Tailwind и тема antd

Стили antd вынесены в CSS-слой `antd` между `base` и `utilities` Tailwind, поэтому утилиты Tailwind переопределяют antd без `!important`.
