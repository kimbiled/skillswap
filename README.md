# SkillSwap KZ

Лендинг пилота SkillSwap KZ — бесплатной доски обмена навыками для студентов Астаны.

Стек: React 19, TypeScript, Vite, Tailwind CSS 4, Ant Design 6.

## Запуск

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # проверка типов и сборка в dist/
npm run preview   # просмотр собранной версии
```

## Как работает обмен

1. Регистрация (`/register`): фамилия, имя, возраст, вуз, Telegram, навыки «научу» и «хочу научиться». Телефон не спрашиваем. До 18 лет — с согласием родителей.
2. Доска (`/board`): Telegram автора открывается только зарегистрированным, по клику «Показать Telegram».
3. После этого две кнопки: «Связались, договорились» или «Ничего не вышло». После выбора объявление уходит с доски.
4. «Мои обмены» (`/me`): прогресс «Связались → Назначили дату → Встретились → Урок прошёл».
5. На последнем шаге — оценка, отзыв и по желанию фото с урока или скриншот переписки. Отзыв появляется в объявлении автора.
6. Premium оплачивается через WhatsApp: кнопка открывает чат с готовым сообщением, счёт отправляется вручную. Номер задаётся в `WHATSAPP_PHONE` в `src/data.ts`.

**Сейчас это демо без сервера.** Анкеты, обмены и отзывы хранятся в `localStorage` браузера, поэтому другие люди их не видят. Вся работа с данными собрана в `src/lib/store.ts` — для запуска с реальными пользователями нужно заменить этот файл на бэкенд (например, Supabase) с настоящей авторизацией.

## Структура

- `src/data.ts` — тексты лендинга, список навыков, номер WhatsApp
- `src/lib/store.ts` — данные и действия (регистрация, обмены, отзывы)
- `src/pages/` — доска и «Мои обмены»
- `src/sections/` — секции лендинга и форма регистрации (`Join.tsx`)
- `src/components/` — навигация, карточка объявления, «бумажные» элементы
- `src/index.css` — токены Tailwind и стили листовок
- `src/theme.ts` — тема antd в той же палитре

Стили antd вынесены в CSS-слой `antd` между `base` и `utilities` Tailwind, поэтому утилиты Tailwind переопределяют antd без `!important`.

## Перед запуском в продакшн

- Подключите бэкенд вместо `src/lib/store.ts` (см. выше).
- Укажите номер в `WHATSAPP_PHONE` в `src/data.ts`.
- Замените `hello@skillswap.kz` на настоящую почту.
